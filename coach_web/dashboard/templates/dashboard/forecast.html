模型架构说明

框架：TensorFlow 2.21 + Keras 3 构建 Sequential 网络
结构：Input(6×1) → LSTM(64) → Dropout(0.2) → LSTM(32) → Dropout(0.2) → Dense(16) → Dense(1)
训练：6 个月滑动窗口单变量预测，4 条序列联合训练，Adam / MSE / 150 epochs + EarlyStopping
验证：Walk-forward，前 18 月训练 → 后 6 月回测，计算 MAE / MAPE / RMSE
归一化：MinMaxScaler，模型与参数已持久化为 lstm_sales.keras / scaler.json
数据口径说明：原始数据为 2026-09 单次采集的截面快照，月度序列依据各对象近 12 个月 真实累计销量（整体 145,549 件），结合电商行业季节因子（双11×2.6、618×1.55、春节×0.55）拆解为 2024-10 至 2026-09 共 24 个数据点；接入真实月度销售流水后，模型代码可直接复用重新训练。
